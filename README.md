# InternPilot

InternPilot 是面向大学生的实习岗位匹配与求职管理智能体项目，围绕岗位获取、匹配分析、个人档案管理、招呼语生成和投递跟进构建完整流程。目前已完成可交互的网页原型，后续将接入真实招聘平台数据、大模型和后端服务。

## 当前状态

当前仓库是可运行、可编辑的前端交互原型，使用 HTML、CSS 和原生 JavaScript，无前端依赖安装或构建步骤。

在线原型：https://internpilot-ui.valid-moose-4187.chatgpt.site

- 登录页、演示账号切换和退出登录。
- 搜索结果初筛、条件说明、单个或批量选择入池。
- 我的岗位池：全部跟进 / 只看收藏 / 已归档；支持手动添加、移出、归档和恢复。
- 岗位详情与助手并排显示，选中文字后可点击“向助手提问”。
- 个人档案：求职偏好、简历材料、经历与能力；事实确认后保存，支持编辑、删除和撤回。
- 招呼语草稿编辑、复制，以及投递状态、日期、备注和批量操作。

**当前岗位、企业、匹配分数、任务进度和助手回复包含示例或规则演示；没有连接真实招聘平台或大模型。账号是浏览器本地演示账号，不是真实身份认证，数据也未云端同步。**

## 本地运行

克隆仓库后进入项目目录：

```sh
git clone https://github.com/jiangcan04/internpilot.git
cd internpilot
python3 -m http.server 8000 --directory dist
```

浏览器访问 http://localhost:8000 。停止服务时在终端按 Ctrl+C。私有仓库需要先获得访问权限并配置自己的 GitHub 认证。

本地记录与浏览器和访问地址有关；线上原型中的浏览器记录不会自动同步到本地。未接入真实账号前，请用示例材料体验。

## 代码结构

| 文件 | 内容 |
|---|---|
| dist/index.html | 入口与脚本加载顺序 |
| dist/style.css | 全部页面样式 |
| dist/app.js | 基础状态、工作台框架与演示任务 |
| dist/experience.js | 引用提问、助手与经历能力档案 |
| dist/job-pool.js | 搜索结果、岗位池、收藏、归档、手动添加与撤回 |
| dist/auth.js | 演示账号登录、切换和退出 |
| checks.cjs | 原有业务行为检查 |
| checks-auth.cjs | 账号行为与完整重载检查 |

脚本按 app → experience → job-pool → auth 加载；后续脚本会替换部分基础函数。`dist/` 在本项目中是直接维护的源文件目录，请提交其中的修改。

## 开发交接

先读 [开发交接说明](docs/DEVELOPER_HANDOFF.md)，其中列出了功能边界、接口草案、现有函数的接入位置、产品规则和验收场景。完整原型说明见 [PROTOTYPE_NOTES](docs/PROTOTYPE_NOTES.md)。

优先跑通：**真实获取岗位 → 匹配分析 → 人工选择入池 → 保存投递记录**。

待接入：一个招聘平台的真实获取工具、大模型服务、后端接口、数据库、真实账号认证；简历文件上传解析需另行实现。保留现有人工确认、来源追溯和错误恢复机制。

不包含：简历撰写、自动投递、自动发送招呼语、HR 回复监测。

## 检查

安装 Node.js 后，在项目根目录执行：

```sh
node checks.cjs
node checks-auth.cjs
```

当前通过 85 项原有行为检查、16 项账号行为检查及 1 项完整账号重载检查。这些是简化 DOM 的逻辑检查，不代表浏览器视觉验收或真实平台集成测试。
